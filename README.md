# ✨ Personal Portfolio Website

> A creative space to showcase my work, explore my interests, and document my journey into web development.

## 💻 About the Project

Designed and developed a personal portfolio website using HTML5 and CSS3, featuring a structured layout, styled sections, project showcases, and a contact interface.

## 🚀 What's Inside?

- **Personal Introduction** — A dedicated space to learn about me.
- **Interests & Projects** — Showcasing my interests and web development projects.
- **Contact Interface** — A form layout for user enquiries.
- **Social Connections** — Links to my professional and social profiles.
- **Multi-page Navigation** — Connecting the Home and Contact pages.

## 🛠️ Tech Stack

`HTML5` · `CSS3`

## 🎯 Project Goal

To strengthen my frontend development fundamentals through hands-on practice in webpage structuring, styling, and navigation.
